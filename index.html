Recommendations

Action Plan
P0

Fix robots.txt and sitemap.xml serving HTML

Dev Team

Root Cause: SPA catch-all rewrite intercepts all routes including /robots.txt and /sitemap.xml

Option A (Minimum)

Exclude /robots.txt and /sitemap* from rewrite rules in CDN/origin config

Option B (Ideal)

Serve static files from origin, generate dynamic sitemap from database

Validation
curl -s https://newsroom.dna.online/robots.txt | head -5

Expected: "User-agent:" not HTML

P0

Implement SSR/Pre-rendering for public pages

Dev Team

Root Cause: CSR-only architecture means crawlers see empty HTML shell

Option A (Minimum)

Use prerender.io or similar service for critical pages (home, listings, top posts)

Option B (Ideal)

Migrate to SSR framework (Next.js, Nuxt) for all public routes

P0

Replace template placeholders with real URLs

Dev Team

Root Cause: {{link}}, {{url}}, {{fileLink}} not resolved server-side

Crawlers see literal placeholder text instead of actual URLs, preventing discovery.

P1

Add server-side metadata (title, description, OG tags)

Dev Team

Root Cause: Metadata generated only client-side via JavaScript

119/119 pages missing meta descriptions. Titles empty or duplicated.

P1

Implement JSON-LD structured data

Dev + Content

Add schemas: Organization (home), NewsArticle (posts), BreadcrumbList (navigation), FAQPage (FAQ)

P1

Block/noindex admin routes

Dev Team

Add to robots.txt Disallow + X-Robots-Tag: noindex for /administrators/*, /companies/view-login, /microsoft/login
